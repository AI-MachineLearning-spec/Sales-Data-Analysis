# Sales-Data-Analysis
I have proceeded to create an interactive and elaborative DASHBOARD project in EXCEL. This has been as a result of a robust process of data processing, data cleaning, visualization and regrouping. 


## Metrics (KPIs)
-	What is the Total Revenue?
-	What makes the total number of orders?
-	What is the total unit count distributed through sales channels
-	What is the average order value?
-	What is the monthly revenue trend?
-	Visualize the regional performance
-	Visualize the product category performance
-	What is the distribution of the sales channels?
-	Visualize products by Revenue.
